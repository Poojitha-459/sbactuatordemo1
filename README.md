Spring Boot Actuator Demo

Project Description

This project demonstrates the implementation of Spring Boot Actuator to monitor and manage a Spring Boot application.

Technologies Used

- Java
- Spring Boot
- Spring Boot Actuator
- Maven
- REST API

Features

- Monitoring application health using "/actuator/health"
- Viewing application information using "/actuator/info"
- Checking application metrics using "/actuator/metrics"
- Viewing Spring Beans using "/actuator/beans"
- Exploring application environment properties using "/actuator/env"
- Exposing and managing Actuator endpoints

Purpose

The main purpose of this project is to understand Spring Boot Actuator and how it helps monitor application health, performance, and internal information.

How to Run

1. Clone the repository.
2. Open the project in Eclipse .
3. Update Maven dependencies.
4. Run the Spring Boot application.
5. Access Actuator endpoints through the browser or Postman.
